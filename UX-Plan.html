CleanFlow UX Plan

Comprehensive UI/UX strategy for the cleaning company SaaS — auditing current state, defining the design system, and planning page-by-page improvements.

Issues & Opportunities
Design System
Page Plan
Progress
Empty States Are Missing High

Tables and lists show "No items found" with no guidance. Users need clear next steps when data is empty.

Affects: CRM, Scheduling, Inventory, Invoicing, Checklists, Dispatch

Fix: Add illustrated empty states with a headline, description, and primary CTA button (e.g., "Add your first customer").
No Global Search High

Users must navigate through the sidebar to find anything. No command bar or global search exists.

Affects: All pages with data lookup

Fix: Add a Cmd+K command palette that searches customers, jobs, invoices, and cleaners across the app.
Sidebar Is Static Medium

The sidebar has 19 items in 5 sections with no way to collapse, pin favorites, or reorder. It will become unwieldy as features grow.

Fix: Add collapsible sections, a "Favorites" area, and a collapsed icon-only mode. Consider a horizontal top nav for primary sections.
No Loading States Medium

When Supabase is connected, data fetches will have latency. Currently no skeleton loaders or spinners exist.

Fix: Add skeleton placeholders for tables, cards, and charts. Use shimmer animation for perceived performance.
No Feedback on Actions Medium

Actions like "Mark Paid", "Clock Out", "Restock" give no success/error feedback. Users can't confirm the action worked.

Fix: Add toast notifications (top-right) for all mutations. Include undo for destructive actions.
No Bulk Actions Low

Users can't select multiple items for batch operations (e.g., delete multiple customers, assign multiple jobs).

Fix: Add row checkboxes and a bulk action bar that appears on selection.
No Keyboard Shortcuts Low

Power users have no way to navigate or act via keyboard. No hotkeys for common actions.

Fix: Add shortcuts: Cmd+N new item, Cmd+/ search, Esc close modal, J/K navigate lists.
No Onboarding Flow Medium

New users see an empty dashboard with no guidance on how to set up their first customer, cleaner, or job.

Fix: Add a setup wizard that walks through: create company → add cleaners → add first customer → schedule first job.
Inconsistent Detail Panels Low

Some pages use right-side drawers (CRM, Scheduling), others use modals (Inventory, Reminders). Pattern should be consistent.

Fix: Standardize: use a slide-over panel for detail views, modals for create/edit forms. Never nest modals.
No Mobile Responsiveness High

The sidebar is fixed at 240px and pages use rigid grid layouts. The app will break on tablets and small screens.

Fix: Add responsive breakpoints: sidebar becomes bottom nav on mobile, tables become cards, grids collapse to single column.
No Dark/Light Mode Toggle Low

The app is hardcoded dark. Some users (especially on mobile) prefer light mode. No toggle exists.

Fix: Add a theme toggle in the header. Respect prefers-color-scheme by default, allow override.
